# Documento de Análisis y Diseño: Matrices de Entradas, Procesos y Salidas (E-P-S)

## Sistema Bancario y Cajero Automático Embebido (ATM Kiosk) - Versión 2.2.0
### Red Multicajero, Red Interbancaria TCP 5000 y Accesibilidad Integral
### Banco Nacional Inzano GYT (`BANC02`)

Este documento formaliza la ingeniería de requerimientos y especificación transaccional del sistema conforme a la metodología rigurosa de matrices de **Entradas (E), Procesos y Reglas de Negocio (P), y Salidas (S)**.

### 2. Estructura de Persistencia Dual en Archivos Planos (.txt)

Cada transacción u operación administrativa ejecuta atómicamente la mutación en la base de datos relacional y actualiza los archivos ubicados en `./data/storage_txt/`:

1. **`usuarios.txt`**
   - Formato: `ID_USUARIO|NOMBRE_COMPLETO|TARJETA_ACTUAL|PIN_HASH|SALDO_ACTUAL|MONTO_MAX_DIARIO|TOTAL_RETIRADO_HOY|CAMBIO_PIN|ULTIMO_ACCESO`
   - Propósito: Catálogo maestro de usuarios y control de límites diarios.

2. **`cajero_inventario.txt`**
   - Encabezado: `TOTAL_BOVEDA|{monto_consolidado}`
   - Denominaciones: `DENOMINACION|CANTIDAD_BILLETES|SUBTOTAL`
   - Propósito: Control físico de cartuchos y validación del límite máximo de Q30,000.00.

3. **`cajeros_red.txt`**
   - Formato: `ID_CAJERO|NOMBRE|UBICACION|ESTADO|INICIALIZADO|CODIGO_CAJERO|EN_LINEA`
   - Propósito: Registro plano de las terminales de autoservicio de la institución.

4. **`transacciones_historico.txt`**
   - Formato: `ID_TX|TIMESTAMP|ID_CAJERO|ID_USUARIO|TIPO|MONTO|DESGLOSE_JSON`
   - Propósito: Histórico financiero inmutable con trazabilidad de billetes por cajero.

5. **`transferencias_interbancarias.txt`**
   - Formato: `ID_TRF|TOKEN|BANCO_ORIGEN|CTA_ORIGEN|BANCO_DESTINO|CTA_DESTINO|MONTO|ESTADO|FECHA`
   - Propósito: Registro de transacciones interconectadas sobre TCP 5000 con formato `TRF-...`.

6. **`auditoria_eventos.txt`**
   - Formato: `ID_LOG|TIMESTAMP|ID_CAJERO|ID_USUARIO|ACCION|DETALLES`
   - Propósito: Pista forense de seguridad bancaria con identificación de terminal y usuario.
